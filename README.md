# Relationship Compass

「何回連絡した・話した・遊んだ」ではなく、会話の内容と相手から返ってくる反応から、現在の関係を10段階で記録するローカルアプリです。

## 関係を自然に進める流れ

1. 相手から返っている反応を基準に、現在の関係段階を選ぶ
2. 会話の10レベルから、今の関係に合う深さを選ぶ
3. 「次の5%ステップ」から一つだけ選び、自分の言葉に直す
4. 実行後の反応を「半歩返った・自然に成立・薄かった」で記録する
5. 相互サインが揃った時だけ、次の一段へ進む

ハート1個が関係性の1段階です。時間経過や接触回数だけでは増減しません。

## 会話の10レベル

1. 安心とリアクション
2. 事実を具体にする
3. 情報から感情へ
4. キャラを一緒に見つける
5. 相互ユーモアと悪乗り
6. 恋愛観への入口
7. 弱さと失敗を交換する
8. 過去と人間関係を理解する
9. 価値観と二人の文脈
10. 日常・未来・関係の確認

各レベルに、会話の進め方、自然な言い方、覚えておく情報、人物別メモに加えて、次の3つを表示します。

- 深い関係を作るための深め方
- 訂正可能な仮説で本音を広げる言い方
- 断る・保留・別案を選べる誘い方
- 次へ進める相互サイン

仮説は断定せず本人が訂正できる形にし、いじりは互いに笑える範囲だけ、誘いは拒否しても関係上の不利益がない形にしています。

## 会話しながら人物理解を育てる

各関係段階には、会話の中で自然に知っておくと次の話題につながる情報が3つ表示されます。入力内容は既存の基本情報・メモへ直接保存されます。

- 名前の読み方・呼ばれ方
- 趣味、好き嫌い、話しやすい話題
- 性格、価値観、共通点
- 行きたい場所、二人の思い出
- 悩み、望む関係、尊重すべきペース

質問攻めにするための項目ではありません。相手が自然に話した時に記録し、次回の会話で丁寧に覚えておくために使います。

従来の人物情報、写真、出来事、メモ、JSONエクスポート／インポートは引き続き利用できます。

## ローカルで実行

```powershell
npm install
npm run dev
```

本番ビルドは `npm run build` です。データはIndexedDBに保存されます。
