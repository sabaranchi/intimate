# 関係性グラデーションアプリ

「何回連絡した・話した・遊んだ」ではなく、会話の内容と相手から返ってくる反応から、現在の関係を10段階で記録します。

## 10段階とハート

ハート1個が関係性の1段階です。

1. 初対面・認知
2. 顔見知り
3. 普通に話せる
4. 個人的交流
5. やや親しい
6. 1対1へ移行
7. 1対1が続く
8. 親密化・軽い好意
9. 好意が見える
10. 告白直前

人物ごとに現在の段階を選ぶと、その段階で自然な5つのトークデッキ、次へ進むための相互サイン、次にできること、避けたい進め方が表示されます。

次段階へ進む基準は回数ではありません。「自分が一歩進めた時、相手から半歩〜一歩返ってきたか」を複数のサインで確認します。基本は今いる段階の一つ先までとし、相手が断ったり流したりできる余白を残します。

## 会話の記録

話すたびに「話した日・内容・相手から返ってきた反応・印象に残ったこと・次に聞いてみたいこと」を短く残せます。積み重ねが関係の地図になり、「ふたりの歩み」（記録した会話の回数、最初の記録からの日数、次の誕生日まで）として上部に表示されます。

## 人物ページ

1つの画面に「関係／基本情報／出来事／メモ」のタブがまとまっています。入力は自動保存されます。既存の人物情報・写真・出来事・メモもそのまま引き継がれます。以前の行動加点や、時間経過だけによる親密度の減点は行いません。
