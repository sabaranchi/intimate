# 関係性グラデーションアプリ

こなした回数ではなく、会話の内容と相手から返ってくる反応から、いまの関係を10レベルで記録し、次の一手を考える攻略ツールです。

## 2つのトラック

自分と相手の性別から自動で切り替わります（人物ページで手動上書きも可）。

- **友情トラック**（同性 / 性別未設定）: 初対面 → 顔見知り → … → 弱さも見せ合える → **親友**
- **ロマンストラック**（異性）: 初対面 → やや親しい → 1対1へ移行 → … → **告白直前**

各レベルで「自然な5つの話題」「今のレベルに合う会話（型・言い回し・深掘り）」「次の一手（マイクロステップ）」「レベルアップの条件」「押さえておくこと」が出ます。

**レベルアップの条件は回数ではありません。** 「自分が一手進めた時、相手からリアクションが返ってきたか」を複数のサインで確認します（相手が反応していないのにレベルが上がらない＝ゲームとしての手応え）。

## 自分の設定

メニュー →「自分の設定」で、名前・性別・自己診断タイプ・聞き役↔話し役・自己開示の傾向・好き/苦手/価値観を登録します。トラックの自動判定と「自分の傾向」ヒントに使われます。

## 相手のタイプ

7タイプ（落ち着き・慎重／明るい・社交／さばさば・自立／クール・論理／甘え・かまって／控えめ・内向／距離が必要）から選ぶと、最初の一言・刺さる動き・やらかしやすい点が出ます。

## 会話の記録

話すたびに「話した日・内容・相手から返ってきた反応・使えるネタ・次に聞いてみたいこと」を残せます。「記録」タブで会話と出来事が時系列にまとまります。

## 人物ページ

1画面に「関係／基本情報／記録／メモ」のタブ。入力は自動保存されます。

## ローカルで実行

```powershell
cd C:/Users/saver/Downloads/my_content/intimate
npm install
npm run dev
```

データはIndexedDBに保存されます。バックアップはメニューのエクスポート（写真・自分の設定も含む v2 形式）／インポートを使ってください。起動時に永続化を要求しますが、こまめなエクスポートを推奨します。
