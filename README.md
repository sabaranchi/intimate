# 人のノート｜山田モード

会話の攻略や関係の採点ではなく、気負わず人と話すための小さなノートです。

## 使い方

- 自分の「山田モード」に、4テーマ・12個の小さな練習を追加。「話しかけやすさ／素直な興味／裏表のなさ／一緒に楽しむ」から一度に一つ選び、行動・注意点・クリアの目安を確認できます。順番は自由です。
- 実際にできたら自分でクリアし、任意で気づきを残します。クリア数・日付・メモを保存し、再挑戦や取り消しは「もう一度練習する」から。メモは残ります。期限・連続日数・相手の反応による採点はありません。
- 選んだ練習は人物の「会う前」にも折りたたんで表示します。練習のクリアは親密度のハートを変えません。記録は自分の yamadaPractice に保存し、以前の自己記録と分離しています。
- 人物を開くと「会う前」に、今の段階での「すること・ひと言・接し方」を一つずつ表示します。友達用・気になる人用の各10段階は、山田の人物像を参考にした独自の例です。
- 自分の性別は「山田モード」のプロフィール、相手の性別は追加時または「基本情報」で設定。同性なら友達、異性なら気になる人に自動切替します。未設定・その他の場合のみ相手ごとに選べます。自分ページの気分の選択は、この自動判定を上書きしません。
- ハート1個＝1段階。「今の段階を見直す」で1〜10を選択し、下げる・未設定に戻すこともできます。以前の段階は引き継ぎ、会話回数で自動的に上げることはありません。
- 人物ページは「会う前／基本情報／思い出／メモ」。覚えておきたい約束や話題を一つ置き、話したあとに任意でひと言を残せます。
- 基本情報、写真、出来事、自由メモ、ライフストーリーは引き続き編集できます。カレンダーは誕生日と明示的に設定した予定のみを表示します。

## 以前のアプリからの変更

ハートと10段階は現在地の目安として復活させ、長いフローの代わりに今の段階の短いガイドを表示します。タイプ診断・攻略チェック・365課題・月次採点は戻していません。過去の人物・会話・写真・メモ・自己記録は削除せず、従来のIndexedDBとv2バックアップ形式を維持しています。段階は既存の communication.relationshipStage を使い、旧スコアやチェック項目は変更しません。ハートは相手の好意や告白成功の確率ではありません。

メニューのエクスポートで写真と自分の記録も一緒に保存できます。インポートは現在の人物を置き換えるため、事前のバックアップを推奨します。

## 人物像について

『正反対な君と僕』山田健太郎の、飾らない関心・素直さ・友達との気軽さをヒントにした非公式のアプリです。画面の文言は独自の解釈で、原作の台詞ではありません。

参考：[公式人物紹介](https://sh-anime.shochiku.co.jp/seihantai_anime/character/%E5%B1%B1%E7%94%B0)、[公式第5話紹介](https://sh-anime.shochiku.co.jp/seihantai_anime/story/%E7%AC%AC5%E8%A9%B1-%E8%80%83%E3%81%88%E3%82%8B%E4%BA%BA%E3%80%81%E8%80%83%E3%81%88%E3%81%AA%E3%81%84%E4%BA%BA)

## 開発・検証

```sh
npm install
npm run dev
node scripts/test-yamada.mjs
node scripts/test-yamada-practice.mjs
npm run build
```

旧ハウツーのデータファイルは履歴・互換確認用に残していますが、新しい画面からは読み込みません。データ保持、空入力、日付順、モード設定、バックアップ互換をテストします。
