# Relationship Compass

「何回連絡した・話した・遊んだ」ではなく、会話の内容と相手から返ってくる反応から、現在の関係を10段階で記録するローカルアプリです。

## 関係を自然に進める流れ

1. 相手から返っている反応を基準に、現在の段階を選ぶ
2. 会話の5レベルから、今の関係に合う深さを選ぶ
3. 「次の5%ステップ」から一つだけ選び、自分の言葉に直す
4. 実行後の反応を「半歩返った・自然に成立・薄かった」で記録する
5. 相互サインが揃った時だけ、次の一段へ進む

ハート1個が関係性の1段階です。時間経過や接触回数だけでは増減しません。

## 会話の5レベル

1. 事実を具体にする
2. 情報を感情にする
3. キャラ・共感・相互ユーモア
4. 過去・弱さ・価値観
5. 二人だけの文脈と自然な誘い

各レベルに、会話の進め方、自然な言い方、覚えておく情報、この人専用の会話メモがあります。例文はそのまま「次の一歩」に入れて、自分の言葉へ調整できます。

仮説は断定せずに確かめ、いじりは互いに笑える範囲だけ、誘いは断る・保留・別案を選べる形にしています。

## 会話しながら人物理解を育てる

各段階には、会話の中で自然に知っておくと次の話題につながる情報が3つ表示されます。入力内容は既存の基本情報・メモへ直接保存されます。

- 名前の読み方・呼ばれ方
- 趣味、好き嫌い、話しやすい話題
- 性格、価値観、共通点
- 行きたい場所、二人の思い出
- 悩み、望む関係、尊重すべきペース

質問攻めにするための項目ではありません。相手が自然に話した時に記録し、次回の会話で丁寧に覚えておくために使います。

従来の人物情報、写真、出来事、メモ、JSONエクスポート／インポートは引き続き利用できます。

## ローカルで実行

```powershell
npm install
npm run dev
```

本番ビルドは `npm run build` です。データはIndexedDBに保存されます。
