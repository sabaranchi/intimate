# コミュニケーション親密度アプリ

「何回会った・何をした」ではなく、会話の質と相互の自然さから人との距離感を記録するローカルアプリです。

## 親密度の5軸

- 話す内容の深さ（30%）
- 会話の空気感（25%）
- 相手から話しかけられやすさ（20%）
- 自分からの話しかけやすさ（15%）
- 呼び方の近さ（10%）

各項目を0〜4で選び、入力済み項目だけで暫定スコアを算出します。5項目すべて入力すると確定評価になります。時間が空いただけでは親密度を下げません。

人物ページでは、実際の呼び方、最後に話した日、話した内容、会話の雰囲気も記録できます。従来の基本情報・写真・出来事・メモは「基本情報・メモ・写真」から引き続き利用できます。

既存データには架空の会話評価を付けず、最初の評価までは「未評価」として扱います。以前の人物情報、写真、メモ、エクスポートデータはそのまま利用できます。

## ローカルで実行

```powershell
cd C:/Users/saver/Downloads/my_content/intimate
npm install
npm run dev
```

ブラウザでViteが表示するURL（通常は `http://localhost:5173`）を開いてください。

データはIndexedDBに保存されます。端末移行やバックアップにはメニューのJSONエクスポート／インポートを使ってください。
